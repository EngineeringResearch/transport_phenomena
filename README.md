# Transport Phenomena

This repository contains Python scripts and computational examples related to
**transport phenomena**, developed as supporting material for the
**Engineering & Research** educational videos and tutorials.

The repository will grow over time as new topics and examples are covered.

## Repository Structure

Each topic is organized in its own folder, containing the scripts and
supporting material relevant to that topic.

### Current Topics

- [`2D_SteadyState_HT`](./2D_SteadyState_HT/) — 2D steady-state heat transfer

Some general-purpose scripts may be placed directly in the main repository
when they are applicable across multiple topics.

## Tools

Examples in this repository may use open-source scientific computing tools
such as:

- Python
- NumPy
- SymPy
- Matplotlib

Additional tools may be introduced as the repository grows.

## Engineering & Research

These codes accompany educational content from **Engineering & Research**.

Website: https://www.engineeringandresearch.org  
YouTube: @Engineering_and_Research

## Purpose

The material is intended for educational and research-oriented use, with an
emphasis on understanding the mathematical and computational foundations of
transport phenomena.
